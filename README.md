# Creator Community Discord Bot

Один Discord-бот на Python для сообщества YouTube и Twitch. Все slash-команды имеют английские названия, а сообщения, кнопки и панели — на русском. Принцип проекта: **одна команда открывает одну панель**, действия выполняются кнопками, меню и модальными окнами.

## Что уже включено

### Основные панели
- `/welcome` — автоматическое приветствие, канал, текст, ссылки на правила и выбор ролей, автоматическая роль новичка, тестовое сообщение.
- `/rules` — добавление, изменение, удаление, список и публикация правил в выбранном канале.
- `/roles` — настройка и публикация меню самостоятельного выбора ролей.
- `/role_requests` — отдельная система заявок на роли: «Новичок» выдаётся автоматически, «Зритель» — после скриншота подписки на YouTube или Twitch и одобрения администрацией.
- `/voice` — создание временной голосовой комнаты при входе в канал-триггер; владелец может переименовать, изменить лимит, закрыть/открыть, скрыть/показать, пригласить, исключить, передать владельца или удалить комнату.
- `/tickets` — приватные тикеты, роль поддержки, закрытие обращения.
- `/moderation` — предупреждение, тайм-аут, исключение и бан.
- `/giveaway` — розыгрыши с кнопкой участия и автоматическим завершением.
- `/events` — создание официальных запланированных событий Discord и публикация анонса.
- `/statistics` — статистика участников, ботов, голосовых комнат и каналов.
- `/logs` — настройка канала журнала действий.
- `/youtube` — добавление YouTube-каналов по ID и автоматические уведомления через RSS.
- `/twitch` — добавление Twitch-каналов и уведомления о начале эфира через Twitch API.
- `/applications` — заявки в команду с кнопками одобрения и отклонения.
- `/suggestions` — предложения участников с голосованием «за/против».
- `/polls` — создание опросов с реакциями.
- `/levels` — опыт, уровни, монеты и таблица лидеров.
- `/achievements` — достижения за активность.
- `/shop` — магазин ролей за внутренние монеты.
- `/games` — ежедневная награда и простая мини-игра.
- `/settings` — просмотр основных настроек.

### Дополнительные панели
- `/faq` — вопросы и ответы, публикация FAQ.
- `/clips` — приём ссылок на клипы от зрителей.
- `/reminders` — планирование сообщений-напоминаний.
- `/birthday` — участники могут указать день и месяц рождения; администратор задаёт канал поздравлений.
- `/automod` — включение/выключение антиспама и фильтра ссылок.

База данных SQLite создаётся автоматически в папке `data`.

## 1. Установка на Windows

1. Установи Python 3.11 или 3.12 с https://www.python.org/downloads/ и отметь `Add Python to PATH`.
2. Распакуй архив.
3. Запусти `start.bat`. Он создаст виртуальное окружение и установит зависимости.
4. Открой файл `.env` и вставь токен бота в `DISCORD_TOKEN`.
5. Запусти `start.bat` ещё раз.

Ручная установка:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
python bot.py
```

## 2. Установка на Linux / Python-хостинге

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

Команда запуска для хостинга: `python bot.py`.

## 3. Создание Discord-бота

1. Открой https://discord.com/developers/applications
2. Создай приложение и перейди в раздел **Bot**.
3. Создай/скопируй токен и вставь его в `.env`.
4. В разделе **Bot → Privileged Gateway Intents** включи:
   - **Server Members Intent** — приветствия, дни рождения, роли и события участников.
   - **Message Content Intent** — уровни и автомодерация.
5. В **OAuth2 → URL Generator** выбери scopes:
   - `bot`
   - `applications.commands`
6. Выдай боту разрешения:
   - View Channels
   - Send Messages
   - Read Message History
   - Embed Links
   - Attach Files
   - Add Reactions
   - Manage Roles
   - Manage Channels
   - Manage Messages
   - Moderate Members
   - Kick Members
   - Ban Members
   - Move Members
   - Connect
   - Create Events / Manage Events
7. Добавь бота на сервер.

**Важно:** не обязательно выдавать Administrator. Выдай только нужные разрешения. Роль бота должна стоять выше ролей, которые он выдаёт или модерирует.

## 4. Настройка `.env`

Скопируй `.env.example` в `.env` и заполни:

```env
DISCORD_TOKEN=ТВОЙ_ТОКЕН
GUILD_ID=0
TWITCH_CLIENT_ID=
TWITCH_CLIENT_SECRET=
DB_FILE=data/bot.sqlite3
```

`GUILD_ID` — необязательный ID сервера для быстрой синхронизации команд во время тестирования. Для глобальной регистрации оставь `0` (глобальные команды Discord могут появляться не сразу).

### Twitch
Для Twitch-уведомлений создай приложение на https://dev.twitch.tv/console/apps и добавь Client ID и Client Secret. Без них остальные функции работают, но Twitch-уведомления не отправляются.

### YouTube
Для YouTube нужен ID канала формата `UC...`. API-ключ не требуется — используется публичный RSS-канал.

## 5. Первоначальная настройка в Discord

Включи режим разработчика в Discord: **Настройки пользователя → Дополнительно → Режим разработчика**. Затем правой кнопкой на канал, роль или участника → **Копировать ID**.

После запуска:

1. `/welcome` — задай канал приветствия, канал правил, канал выбора ролей и роль новичка.
2. `/rules` — выбери канал правил, добавь правила и нажми «Опубликовать».
3. `/roles` — укажи канал панели и ID ролей, затем опубликуй панель.
4. `/voice` — укажи голосовой канал-триггер и категорию временных комнат.
5. `/tickets` — укажи категорию тикетов, роль поддержки и канал панели, затем опубликуй панель.
6. `/logs` — укажи канал журнала действий.
7. `/youtube` — добавь YouTube Channel ID и канал Discord для уведомлений.
8. `/twitch` — добавь имя Twitch-канала и канал Discord для уведомлений.
9. `/applications`, `/suggestions`, `/faq`, `/clips` — настрой каналы и опубликуй пользовательские панели.
10. `/automod` — включи антиспам и/или фильтр ссылок по необходимости.
11. `/birthday` — участники указывают день рождения, администрация задаёт канал поздравлений.
12. `/reminders` — создавай запланированные сообщения.

## 6. Важные замечания

- Для временных голосовых комнат нужны `Manage Channels` и `Move Members`.
- Для выдачи ролей роль бота должна быть выше выдаваемых ролей.
- Для модерации роль бота должна быть выше ролей пользователей, которых он модерирует.
- Приветствия, роли и дни рождения требуют Server Members Intent.
- Уровни и автомодерация требуют Message Content Intent.
- YouTube проверяется примерно раз в 3 минуты, Twitch — примерно раз в минуту.
- Постоянные кнопки тикетов, голосовых комнат, розыгрышей, заявок, предложений и клипов восстанавливаются после перезапуска.
- SQLite сохраняет настройки и данные после перезапуска.
- Для работы 24/7 нужен хостинг, который не останавливает Python-процесс.
- Временные комнаты создаются автоматически, когда пользователь входит в настроенный голосовой канал-триггер. Для каждой комнаты бот создаёт отдельный текстовый канал с панелью управления.

## 7. Безопасность

Никогда не отправляй токен бота другим людям и не загружай `.env` в публичный репозиторий. Если токен утёк, сбрось его в Discord Developer Portal.


## Заявки на роли с подтверждением подписки

1. Создай на сервере роли `🆕 Новичок`, `👤 Зритель` и `⏳ На проверке` (последняя необязательна).
2. Создай отдельную категорию для приватных заявок, например `📩 ЗАЯВКИ НА РОЛИ`.
3. Убедись, что у роли проверяющих есть доступ к этой категории.
4. Запусти `/role_requests`.
5. Нажми **Настроить каналы** и укажи ID публичного канала панели, категории приватных заявок и роли проверяющих.
6. Нажми **Настроить роли** и укажи ID ролей «Новичок», «Зритель» и (по желанию) «На проверке».
7. Нажми **Опубликовать панель**.

Участник сможет запросить «Новичок» самостоятельно. Для роли «Зритель» он выбирает YouTube или Twitch, получает приватный канал заявки и прикрепляет изображение подписки. Бот пересылает доказательство в том же приватном канале с кнопками **Одобрить** и **Отклонить**. Решение принимают только администраторы или участники с настроенной ролью проверяющих. При одобрении бот выдаёт роль «Зритель», а временную роль «На проверке» снимает.

**Важно:** бот не может достоверно проверить подписку только по скриншоту автоматически. Администрация должна проверить изображение вручную. Роль бота должна стоять выше ролей «Новичок», «Зритель» и «На проверке».


После обновления дизайна снова нажми `/role_requests` → **Опубликовать панель**. Новое сообщение появится в выбранном канале; старое сообщение нужно удалить вручную.


## Что происходит после решения по заявке

После нажатия администрацией кнопки «Одобрить» или «Отклонить» бот:
- отправляет участнику красивое личное сообщение с результатом;
- указывает платформу и имя администратора, который рассмотрел заявку;
- при одобрении выдаёт роль «Зритель» и снимает «На проверке»;
- при отказе снимает «На проверке»;
- записывает результат в журнал действий;
- через 5 секунд автоматически удаляет приватный канал заявки.

Если у участника закрыты личные сообщения, бот зафиксирует это в журнале, но не сможет доставить уведомление. Для удаления приватного канала боту требуется право `Manage Channels`.
